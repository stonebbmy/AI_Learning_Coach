全流程：Docker Desktop → 拉镜像 → compose build → compose up → 容器内自检。
原则：默认「兜底」—— DaoCloud 拉 Docker Hub 镜像；构建期 apt / PyPI / Maven 走国内镜像（见 Dockerfile），不依赖 Clash 对 PyPI 的 TLS 稳定性。运行期业务外网仍经 compose 注入的 DOCKER_* 代理（本机 Clash）。

════════════════════════════════════
阶段 A — 宿主机与 Docker 引擎
════════════════════════════════════
□ Docker Desktop 已启动。
□ Settings → Resources → Proxies：HTTP/HTTPS 指向 http://127.0.0.1:你的 Mixed 端口（如 7890）。
□ Settings → Docker Engine（JSON）中 proxies 使用 http://host.docker.internal:端口（不要用 127.0.0.1 指向 daemon 内环回），且 "ipv6": false 已合并；Apply & Restart。
□ docker info 中可见 HTTP/HTTPS Proxy（常为 http.docker.internal:3128，属 Desktop 内部转发，可接受）。

════════════════════════════════════
阶段 B — 宿主机验证「代理可用」（运行期业务外网）
════════════════════════════════════
在 PowerShell（宿主机）执行（端口按你的 Clash）：
  curl.exe -x http://127.0.0.1:7890 -I https://api.deepseek.com/
  curl.exe -x http://127.0.0.1:7890 -I https://registry-1.docker.io/v2/
若运行期要调外网 API：此处应能通。构建期 PyPI 已默认走清华索引，不再强依赖 pypi.org 经代理稳定。

════════════════════════════════════
阶段 C — 拉基础镜像（与 compose 默认一致）
════════════════════════════════════
项目根目录（镜像名与 docker-compose.yml 中 image / build 默认一致，可为 DaoCloud 前缀）：
  docker pull docker.m.daocloud.io/library/python:3.11.8-slim-bullseye
失败时：对照 docker/NETWORK.txt「七」（daemon 代理、IPv6、Allow LAN）。

════════════════════════════════════
阶段 D — 构建 ai-service（默认已兜底）
════════════════════════════════════
  docker compose build ai-service

成功标志：builder 阶段 apt 完成、pip wheel 从清华索引下载 whl（构建层已 unset 代理，不经 Clash 访问 pypi.org）。

若仍失败：检查本机到 mirrors.tuna.tsinghua.edu.cn / files.pythonhosted.org 是否可达；可在 .env 中覆盖 PIP_INDEX_URL / PIP_TRUSTED_HOST。

════════════════════════════════════
阶段 E — 启动栈与业务自检
════════════════════════════════════
  docker compose up -d redis chroma ai-service
  docker compose ps
  docker exec aicoach_ai_service sh -c "cd /app && PYTHONPATH=/app python /app/scripts/e2e_network_check.py"

compose 已为运行中容器配置 extra_hosts: host.docker.internal:host-gateway；若 httpx 仍异常，见 NETWORK.txt 与 e2e 脚本说明。

════════════════════════════════════
阶段 F — Java 服务（若需要）
════════════════════════════════════
  docker compose build java-app
  docker compose up -d
Maven 使用 java-app/maven-settings.xml（阿里云 mirror）；构建 mvn 层已 unset 代理。失败时检查到 maven.aliyun.com 的连通性。

════════════════════════════════════
当前仓库侧已就绪项
════════════════════════════════════
• compose：DaoCloud 默认镜像名；build.extra_hosts + 运行 extra_hosts（host.docker.internal）。
• ai-service Dockerfile：清华 Debian apt；清华 PyPI + pip 层无代理。
• java-app：清华 Ubuntu apt；阿里云 Maven。
• docker/NETWORK.txt：Docker Desktop / 代理说明。
